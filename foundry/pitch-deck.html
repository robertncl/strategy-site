Foundry proposal02

The problem

Power users hit the wall mid-month.

  • Premium allowance exhausted by week 2–3 for power users
  • Agentic and long-context tasks burn multipliers fastest
  • Bulk work — refactors, tests, docs — wastes premium calls
  • Overage either blows the budget or gets blocked

One model tier for every task is the inefficiency.

A premium frontier model answering “rename this variable across the repo” is top-rate pay for routine work.

Foundry proposal03

The idea

Add a cheaper second lane.

Keep GitHub Copilot for what it's best at — inline completions and tightly integrated chat. Add Azure AI Foundry for the high-volume, long-context work. Send each task to the model that does it best, for the least money.

Lane 1 · Keep

GitHub Copilot
