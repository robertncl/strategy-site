Three products, one idea
Pick the surface that matches who’s building.
For developers
GitHub Copilot — local & cloud sandboxes
Runs shell commands and repo edits inside a contained box — on your machine (/sandbox enable) or in an ephemeral cloud container (copilot --cloud). The coding agent gets one container per task; nothing merges without human review. Public preview as of June 2026.
For makers
Copilot Studio — the code interpreter sandbox
Low-code agents run Python on Excel, Word, PowerPoint, and PDF files inside an isolated, Microsoft-hosted VM — no external network, no system commands, live-monitored. Off by default; a tenant admin turns it on per environment.
For builders & pros
Azure AI Foundry — code interpreter & hosted agents
Code-first agents run Python for analysis, math, and charts on Azure Container Apps dynamic sessions, each behind a Hyper-V boundary with no outbound egress. Sessions run up to 1 hour with a 30-minute idle timeout, pinned to your project’s region.
One isolation engine powers all three.
Whatever the front door, the untrusted code lands on the same substrate: an ephemeral, Hyper-V-isolated container on Azure Container Apps. Same posture whether the caller is a developer, a maker, or a service.
